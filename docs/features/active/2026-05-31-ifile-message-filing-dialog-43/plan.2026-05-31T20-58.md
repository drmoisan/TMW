## Plan conventions

- Each task is atomic: one concern, one binary acceptance criterion, explicit file paths.
- The 500-line production/test file cap is enforced; modules are split proactively.
- Every phase that changes code ends with the full seven-stage toolchain loop (format → lint → type-check → architecture → unit/property → contract → integration) for each language touched in that phase. Restart from stage 1 on any failure or auto-fix.
- Both languages have mandatory coverage policy (line >= 85%, branch >= 75%, no regression on changed lines). Baseline and final-QC tasks capture numeric coverage.
- AC verification class: AC-2, AC-3, AC-11, AC-12, AC-13, AC-19, AC-20, AC-21, AC-24 are manual or partly manual per `spec.md`. All others are CI-verifiable.
